*gjallarhorn.txt*  Odin completion for Vim

Author: solver42

============================================================================
COMPLETION                              *gjallarhorn-completion*

Type Ctrl+X Ctrl+U to get completions. Use Ctrl+N / Ctrl+P to navigate.

Completions for:
- Struct fields, enum values, type aliases
- Imported library symbols
- Chained member access (e.g. "a.b.c.")
- Unqualified prefix match (struct, enum, variable)

============================================================================
HOVER                                   *gjallarhorn-hover*

Press K to toggle a popup showing the full definition of the symbol
under the cursor. Press K again to close the popup.

============================================================================
GO TO DEFINITION                        *gjallarhorn-goto*

Press gd on any symbol to jump to its definition. Opens the file and
moves the cursor to the definition location. Falls back to Vim's
default gd behavior if the daemon cannot find a definition.

============================================================================
CONFIGURATION                           *gjallarhorn-config*

Set |g:gjallarhorn_bin| in your vimrc to customize the daemon path:

let g:gjallarhorn_bin = '~/.local/bin/gjallarhorn'

Defaults to ~/.local/bin/gjallarhorn.

Additional timeout settings:

let g:gjallarhorn_startup_timeout = 5000
let g:gjallarhorn_request_timeout = 3000

============================================================================
DAEMON                                  *gjallarhorn-daemon*

Gjallarhorn runs as a background process that listens on a Unix socket.
The daemon is started automatically when you open a .odin file and
lives for the duration of your Vim session. No manual action needed.

The daemon re-indexes changed files on save. Files whose content has
not changed (detected via MD5 hash) are skipped.

Project root detection               *gjallarhorn-root*

When you open a .odin file, gjallarhorn walks up the directory tree
until it finds a marker file or directory:

- .git
- .editorconfig
- gjallar.horn

The directory containing the first marker becomes the project root.
To mark a root explicitly, create a gjallar.horn file in that directory:

touch gjallar.horn
