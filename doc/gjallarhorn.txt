*gjallarhorn.txt*  Odin completion for Vim

Author: solver42

==============================================================================
USAGE                                   *gjallarhorn-usage*

Open an *.odin file. In insert mode, type a name followed by a dot, then press
Ctrl+X Ctrl+U to get completions. Use Ctrl+N / Ctrl+P to navigate.

Completions for:
  - Struct fields, enum values, type aliases
  - Imported library symbols
  - Chained member access (e.g. "a.b.c.")
  - Unqualified names (struct name, enum name, variable, followed by dot)

The daemon re-indexes on save. No manual action needed.

==============================================================================
CONFIGURATION                           *gjallarhorn-config*

Set |g:gjallarhorn_bin| in your vimrc to customize the binary path:

  let g:gjallarhorn_bin = '~/.local/bin/gjallarhorn'

Defaults to ~/.local/bin/gjallarhorn.

==============================================================================
DAEMON                                  *gjallarhorn-daemon*

Gjallarhorn runs as a background process that listens on a Unix socket. It
persists between Vim sessions and re-indexes files on save.
